# ⬢ NexusForge

> Forge your freelance business.

NexusForge is a freelancer workspace designed to bring clients, projects, tasks, notes, invoices, and business activity into one place.

Instead of jumping between multiple tools, freelancers can manage their work from a single workspace.

## ✨ Current Features

### 👥 Client Management
- Create and manage clients
- Store contact information
- Client status tracking
- Client notes with Markdown
- Client activity history
- Project count per client

### 📁 Project Management
- Create projects
- Project status and priority
- Project budgets and currencies
- Start and due dates
- Project progress
- Project tasks
- Project activity history

### ✅ Task Management
- Create tasks
- Task status tracking
- Task priorities
- Task filtering
- Task deletion

### 📝 Notes
- Markdown editor
- Preview mode
- Project/client notes

### 📊 Dashboard
- Workspace overview
- Client count
- Project count
- Client overview
- Workspace-based navigation

### 🔐 Authentication
- Email/password authentication
- Google authentication
- Protected routes
- Session management
- Email verification
- Password reset
- Password change
- Account deletion

### ⚙️ Settings
- Profile management
- Password management
- Appearance preferences
- Account deletion
